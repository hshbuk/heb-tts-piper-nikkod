\# Bilingual TTS Server (Hebrew \& English)



שרת Text-to-Speech מקומי מבוסס Flask, המשלב את מודל הניקוד Phonikud עם מנוע הדיבור Piper ליצירת הקראה חלקה וטבעית בטקסטים מעורבים (עברית ואנגלית). השרת מיועד לעבוד כ-Backend עבור תוסף דפדפן (Firefox Extension).



\## תכונות מרכזיות

\* \*\*הפרדת שפות אוטומטית:\*\* זיהוי ופיצול חכם של משפטים המכילים עברית ואנגלית, תוך שמירה על גבולות מילים.

\* \*\*נרמול פונטי מתקדם בעברית:\*\*

&#x20; \* המרת קמץ קטן/חולם לפני ו' לחולם מלא תקני.

&#x20; \* הסרת שווא נע מלאכותי בצרורות עיצורים סופיים.

&#x20; \* הפרדת מילות יחס (כמו "עם") למניעת היבלעות פונטית.

\* \*\*הפקת אודיו ישירה:\*\* החזרת קובץ `WAV` רציף ומחובר ישירות בתגובת ה-API.



\## התקנה והרצה



מומלץ להשתמש ב-`uv` לניהול הסביבה והתקנת התלויות בצורה מהירה:



```powershell

uv venv

.venv\\\\Scripts\\\\activate

uv pip install -r requirements.txt
```


\### הורדת המודלים



יש להוריד את המודלים הבאים ולהניח אותם בתיקיית השורש של הפרויקט:



1\. `phonikud-1.0.int8.onnx`

2\. `he\_IL-saspeech-medium.onnx` + `he\_IL-saspeech-medium.onnx.json`

3\. `en\_US-bryce-medium.onnx` + `en\_US-bryce-medium.onnx.json`



\### הפעלת השרת



```powershell

python -X utf8 server.py



```



השרת יאזין בכתובת `http://127.0.0.1:5000`.



\## שימוש (API)



שליחת בקשת `POST` לכתובת `/tts` עם גוף JSON:



```json

{

&#x20; "text": "התוכנה פועלת באופן עצמאי עם Firefox Extension."

}



```
